# 后台登录与发布反馈升级

- 首次设定密码：验证服务器原 ADMIN_TOKEN，输入新密码并确认，成功后自动登录。
- 修改密码：登录后顶栏 PASSWORD 入口，需要当前密码和两次新密码。
- 30天免登：HttpOnly Cookie配合服务端有效期，浏览器不保存明文密码或JavaScript可读会话Token。
- 独立门禁：未登录时只有登录/设定卡片，验证会话成功后才显示工作台。
- 上传与发布：按实际上传字节更新百分比，传输100%后等待服务端确认，确认写入后才显示绿色成功。
- 多图上传排队，避免弹窗状态互相覆盖。失败需确认关闭；会话失效回到登录页，编辑草稿保留在当前页面。
- 封面取消灰度、压暗和点阵遮罩，准星与角标保留。

验证：16项Python API测试、4项进度状态测试通过；浏览器验证了登录、刷新免登、密码选项与发布成功HUD。设定/修改密码、失效和撤销通过隔离API测试验证，没有使用或更改真实服务器密码。
