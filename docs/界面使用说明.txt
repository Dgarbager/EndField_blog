三种模式：
NIGHT // 极夜终端：碳素黑 + 工业黄。
DAY // 白昼工程：冷灰白 + 警示黄，细小强调文字使用深金色保证可读性。

总控台顶栏与文章页吸顶栏均有模式按钮，两处状态同步。

浏览器禁止存储时仍可切换当前页面，只是不保存。
颜色在页面绘制前恢复，避免加载时闪回默认主题。
站点标识、刀路示意图、卡片、弹窗、扫描线与警示条随模式切换。
主题切换时有轻量字符解码反馈，遵循系统减弱动态效果设置。
