# 公开档案与零号档案

编辑器的“归档范围”可选择公开档案或零号档案。公开档案归入前三个扇区；零号档案固定使用 SEC_04，仅管理员可读。编辑已有文章时也可切换范围，保存后立即生效。

首页保留第四张“零号档案”入口卡片，不显示私密文章数量。公开列表只显示前三个分类。公开文章列表、搜索、标签筛选、随机漫游、统计、RSS、相邻文章和正文接口均排除 SEC_04，即使请求者已登录也不会混入私密文章。

零号档案使用 private.html 阅读，首次访问跳转现有管理员登录页，验证后返回私密列表或原文章。与后台共用 HttpOnly Cookie、30天有效期、退出与修改密码撤销逻辑；不增加另一套密码。后台管理列表可管理两种范围的文章。

私密正文、列表、统计和本站上传图片统一通过 /api/admin/ 下的受保护接口获取，必须提供有效管理员会话。私密图片上传时即登记权限，未发布的图片也不会通过 /uploads/ 暴露。公开文章切成私密后，本站图片链接自动改为受保护地址；切回公开会恢复公开链接。同一图片被公开文章引用时仍可公开访问；移除最后一处公开引用后恢复私密限制。站外图片仍由原图床控制访问。

启动时自动建立 upload_access / post_uploads 两张表，并迁移现有 SEC_04 文章的本站图片链接及权限。文章编号、时间、正文文字、管理员密码和会话保留。请勿回滚到不具备私密权限校验的旧后端版本。

新增接口（均需要管理员会话）：

| 接口 | 用途 |
|---|---|
| GET /api/admin/posts | 后台统一管理列表 |
| GET /api/admin/posts/{id} | 编辑器读取任意范围文章 |
| GET /api/admin/private/posts | 零号档案列表，支持分页、搜索、标签 |
| GET /api/admin/private/posts/{id} | 私密正文及私密相邻文章 |
| GET /api/admin/private/telemetry | 私密统计 |
| GET /api/admin/files/{path} | 私密图片 |

POST /api/admin/upload 新增 archive=public/private 参数。文章写入仍使用现有接口，通过 sector=SEC_04 指定零号档案。公开详情访问私密编号返回404；私密接口未登录返回401。

验证包括公开接口无泄漏、真实会话校验、私密图片未附文时保护、公开/私密切换、共用图片引用、旧数据迁移及密码修改撤销其他设备访问。
